## 核心决定

1. 从当前 `fsa_stream` 建独立 `fsa_stream_split_d` 研究分支顶层。沿用四个 64-bit AXI bundle、独立 Q/K/V 请求进程、Q 跨 KV 缓存、唯一 Accumulator actor、Raw FMA 和 packed banked SRAM。不要回到 legacy request top。
2. 一个 engine 内按 d 串行分块；多个 engine（后续可选）处理不同 query tile。默认目标 D=128、R=16、BQ=BK=16、E=1。先通过 R=4 的小配置。D 与物理行数 R 必须分离。
3. PE 内保留一个复用的 FP16 `reg`（Q→score→N→X→P），新增 FP32 `score_acc`，并拥有自己的邻接传输寄存器和运算完成状态。不放外部 score/P RAM，不默认增加每 PE FP32 加法器。
4. 下一 d 块的 QK 链以旧 `score_acc` 为 FMA 的 c 输入，链末 FP32 结果直接写回。遍历全部 d 块后才执行 CMP/softmax。首版按全局 feature 递减顺序累加，便于与当前全高阵列对齐。
5. P 在 PE 中保持直到所有 D 个输出 feature 的 PV 结束；每 KV 只生成一组 `MAX_DIFF + ROW_SUM + D×PV`。Acc 的 L 更新一次，每个 O[h] 乘 alpha 一次，最后一个 KV 后归一化全部 D 维。
6. 不要求保持旧 100-step、hop=5 或固定 tile 拍数。完成计数、标签、寄存器读写关系必须精确；插入 PE 内流水级后重新核对调度和回压。
7. 首要论文实验是局部布局与资源均衡、跨区域互连流水化；HBM 绑定和共享 K/V 为后续独立消融。当前已有 Q 缓存、四 bundle、DMA/计算重叠，不能重复归功于 split-d。

## 实施边界

- “寄存器放在 PE 里”同时约束 C++ 状态所有权和综合后物理实现。将全局数组改名为 PE 数组不构成物理局部性证明。
- 保持 FP16 输入/PE 工作值、FP32 部分 score 和 L/O；精度升级另做实验。数据有限值为首版合同，输入越界、溢出和 NaN 行为应明示，不能用普通真实 exp 金标准掩盖 Raw FMA 差异。
- 旧上下文中的“单 SA、一个 elem reg”描述当前迁移基线；本次用户明确要求的 split-d 研究变体允许新增 PE score 状态。E>1 是后续可选实验，不直接改生产基线。
- 保持当前器件、100 MHz 和 2.7 ns uncertainty 的比较条件。不得用放宽时钟掩盖退化。新 Tcl 默认 `RUN_COSIM=0, EXPORT_IP=0`，执行这些步骤遵循仓库要求。
- 所有本次生成物仅在本目录；源码、旧方案、原 PROJECT_CONTEXT 均不改动。没有执行 Git 操作。
