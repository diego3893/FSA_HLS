## 需统一的版本口径

- **数值类型**：完整暑期报告部分段落称“定点数”；本次 `types.hpp` 明确为 `half/float`，已按 FP16/FP32 修正。
- **DMA 接口**：根 README 仍描述固定 4×4、VT/OL 和旧状态码；本次按 `fsa_dma_top.cpp/.hpp` 写为完整序列 Q/K/V/O 行优先布局，状态为 OK=0、非法长度=1、核心协议错误=2。未修改原仓库 README。
- **构建时序**：303 DSP、7.300 ns、27,566 cycles 来自 2026-08-24 归档报告；源码中存在 8 月 26 日及后续演进内容，原始 build 产物未随此快照提供，不能视为新版本重新综合结果。
- **IP 与板测**：8 月 24 日综合报告写未导出、未板测；后续完整暑期报告写 NM37 板测通过。报告按先后阶段表述，需补版本映射。板测说明书声称 IP 已位于 ip_repo，但本次快照的该目录仅包含 README，未见相应 component.xml/导出压缩包。
- **覆盖范围**：现行 DMA testbench 为 L=2×SA_COLS+1、非 causal、一次调用；默认即 L=9。长度 4096 和 head dimension 上限 128 是配置范围，不能当作实测通过范围；causal、非法长度和重复请求也不能从“有代码”直接推定“验证通过”。
- **误差与性能**：0.18 是该测试允许的绝对误差阈值，不是测得的最大误差；275.66 μs 是 27,566 拍按 100 MHz 换算，非主机端到端或板上实测延迟。7.300 ns 是 HLS 估算，不应写为实际 Fmax。
- **优化对比**：2,383 DSP 的早期请求顶层与 303 DSP 的 DMA 顶层属于不同阶段和顶层；正文未给出同条件面积降幅。独立 SA、独立 Accumulator 和 DMA 内嵌模块的资源/II 不应互换。
- **后续架构**：DATAFLOW、accumulator_pipeline、Split-D 与多小型 FSA 均未当作当前正式实现；如已另有分支通过验证，需要另外提供版本和结果。
