## 5 实例、资源与接口

| 资源 | 16×16/head128 HLS估算 | 占VU37P | 4×4/head16正式HLS基线 |
|---|---:|---:|---:|
| LUT | 1221689 | 93.71% | 129412 |
| FF | 231597 | 8.88% | 45889 |
| DSP | 352 | 3.90% | 40 |
| BRAM_18K | 8 | 0.20% | 8 |
| URAM | 0 | 0% | 0 |

4×4列来自bf41d16，形状和head均不同，只供规模开销对照。HLS面积是估算，不能声称16×16已可布局或必定放不下。每块PE本身估算LUT459128，超过单SLR的434560；即使后续物理综合可优化，当前大块跨区及资源压力也需实测，不能直接固定一块进一SLR。

最终RTL只有两个`runPeArray`例化点，各在对应worker的key-loop outline中；两个`runAccumulatorColumns`各在对应worker中。QK/ROW_SUM/PWL/PV子报告出现逻辑调用不表示新增物理实例。

- PE尾数乘法`mul_11ns_11ns_22_2_1`：256个，每块128个、各1DSP。
- Accumulator尾数乘法`mul_24ns_24ns_48_3_1`：16个，每块8个、各2DSP。
- FP32减法`fsub_32ns_32ns_32_3_full_dsp_1`：32个，各2DSP。

因此DSP为`256＋16×2＋32×2=352`，与顶层一致。RawFMA被内联，计数是等效算术通路，不称256个同名peMacUnit RTL模块。[实例树](../evidence/split_d_71025ff_16x16/rtl_instance_tree.txt)与[核对摘要](../evidence/split_d_71025ff_16x16/review.json)保存路径和计算。

每块PE：DSP128/FF52143/LUT459128；每块Accumulator：DSP16/FF9940/LUT56796。两个PE合计估算LUT918256，约占顶层75.16%；更小块不能自动消除浮点算术及共享选择逻辑开销。顶层BRAM_18K8全部来自四路AXI适配器各2；不是算法tile存储的物理BRAM验收结果。

实际顶层四路m_axi的地址及数据均64-bit，控制AXI-Lite数据32-bit、地址7-bit；没有扩至512-bit。Q/K/V读，O写；顶层ap_ctrl_hs通过控制寄存器启动/完成，sequence_length32-bit、causal1-bit、status8-bit。原pragma的max_widen_bitwidth512只是允许的上限。

## 6 与Split-D论文的资源和时间比较

论文《A 16×16 High-Utilization Systolic Array Hardware Accelerator for Long-Sequence Flash-Attention Computation in Transformer》，ASICON2025、DOI10.1109/ASICON66040.2025.11326298。原文Table I/II及实验段已核对。

| 指标 | 本轮 | 论文 |
|---|---|---|
| PE数/head | 256/128 | 16×16/128 |
| 精度 | FP16×FP16＋FP32累加 | INT8/INT16混合 |
| 器件/频率 | VU37P/100MHz目标 | XC7VX690T/200MHz |
| 资源阶段 | HLS估算 | 论文FPGA实现报告 |
| LUT | 1221689 | 91633 |
| FF | 231597 | 168507 |
| DSP | 352 | 544 |
| BRAM | 8个BRAM_18K估算 | 236，原文未明确18K/36K口径 |
| N1024时间 | 无CoSim/板测实测 | 9.83ms |

纯数字上LUT约13.33倍、FF约1.37倍、DSP少35.29%；精度、器件及验证阶段不同，不能据DSP更少宣称更高资源效率。BRAM单位未统一，不计算节省比例。CSim墙钟和最大长度综合延迟不能与论文9.83ms直接比较。

**当前PV调度模型揭示明显吞吐差距：**源码每次只有r==row的V/反馈有效，且只提交该行结果；两个16×8块合计每次16个有效MAC位置，而非256。每块每个满key tile的QK调用128次，PV调用D×H=2048次，另含128次Accumulator更新，PV循环共2176次。减小query块宽B不减少这些调用次数。

N1024非因果有64×64=4096个tile对，每worker的PV共8388608次PE发射。按已核对II5，100MHz下**仅PE发射下界为419.4304ms**；按PV循环10886cycles逐tile相加为445.89056ms的调度模型。这些是源码＋HLS计算，未含全部其他阶段/停顿，不是硬件实测；已经说明不能用`2N²H/(256f)`的全利用率理想公式预测当前实现达到论文时间。

## 7 TAPA启发与后续候选

当前借鉴query空间块、hls::stream及前向DATAFLOW；编译仍为Vitis，未接入TAPA工具链、早期floorplan反馈或距离感知通信插级。FIFO深度8不是8级通信寄存器。4×4已有HLS之后的Vivado物理对照：同次hard区域setup−0.081ns，比自动布局+0.230ns差0.311ns，候选已拒绝；不构成TAPA完整机制的消融实验。

4×4首次分块组合对照94158→80242cycles（−14.78%），FF31923→45091（＋41.25%）、LUT125123→129592（＋3.57%）；含搬运重构，不能单独归因于分块或floorplan。

更小query块候选为四个16×4，总256PE/16Accumulator保持。它可能减少单块端口、控制、调度及布线压力，也会增加K/V本地复制、广播/FIFO与控制开销。当前静态限制仅支持1/2块，四块需结构改动；默认PE_ARRAY_II只按全局D选择，缩小B本身不改解析目标5。收益须同器件、同频率、同精度、同覆盖的对照证明。

恢复工作后的候选优先级：先研究保持逐feature原有逐key行FMA顺序的PV流水，让不同feature同时占用不同key行；再分别测试更小query块和通信/物理流水。不得以并行归约树改变舍入合同，也不得增加完整阵列换吞吐。当前按用户要求暂停，这些未实施、未获本轮扩展验收。
